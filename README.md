# TOY MUSEUM v2

Цифровой паспорт и навигатор физической коллекции designer toys.

## Что внутри
- Главный экран без каталожной «простыни» фотографий.
- Поиск по названию, инвентарному номеру, бренду, серии, персонажу, городу, музею, залу, стеллажу, полке и слоту.
- Фотосканер: CLIP + FAISS, пользовательское фото не сохраняется как экспонат.
- Карточка экспоната-паспорт.
- Навигатор: зал → стеллаж → полка → слот.
- Состояние, оценочная/страховая стоимость, COA, голограмма, коробка, заметки хранителя.
- Пакетная загрузка фотографий и автоматическая нумерация INV-00001, INV-00002…
- Полная админка для редактирования и удаления.
- Защита админки через ADMIN_KEY.
- Отдельный Render worker для Telegram polling.

## Render
Web service:
`gunicorn --bind 0.0.0.0:$PORT app:app`

Worker:
`python bot.py`

Переменные:
- `BOT_TOKEN` — токен Telegram-бота.
- `WEBAPP_URL` — URL web service.
- `ADMIN_KEY` — секретный ключ администратора.
- `FLASK_SECRET` — случайная длинная строка для сессий.

## Важно про хранение
Render filesystem не следует считать постоянным хранилищем для музейного фонда. Для настоящих 15 000+ экспонатов после прототипа лучше вынести SQLite/фото в постоянную БД и object storage. Текущая версия рассчитана на стартовую коллекцию и тестирование UX.
