# Museum Mini App — готовая версия

Это готовая сборка Mini App для каталога игрушек.

### В этой версии
- новый интерфейс Mini App;
- 📷 сканирование игрушки камерой;
- 🔎 поиск по названию, номеру, городу, стране и музею;
- 🌍 отдельный просмотр стран, городов и музеев;
- карточка экспоната с фото и местом хранения;
- CLIP + FAISS для визуального поиска;
- SQLite;
- актуальная `museum.db` с 15 JPG-записями;
- `fill_db.py` заново создаёт записи только для `.jpg` из `photos/`.

## Как поставить

1. Распакуй ZIP.
2. В папку проекта положи свою папку `photos/` с 15 JPG.
3. Если используешь Railway — загрузи содержимое проекта в репозиторий.
4. Локально:

```bash
pip install -r requirements.txt
python app.py
```

Порт берётся из `PORT`, поэтому Railway подходит без изменений.

### Если нужно заново заполнить БД

```bash
python fill_db.py
python app.py
```

`fill_db.py` удаляет старые записи и создаёт по одной записи на каждый JPG.
