# TOY MUSEUM — FINAL PREMIUM + BOT

Готовая версия TOY MUSEUM для одного Render Web Service.

## Что внутри
- Премиальный тёмный интерфейс в стиле присланного референса.
- Иллюстрированный фон галереи.
- Поиск по названию, инвентарному номеру, городу, музею и стране.
- Фотосканер: камера на телефоне + выбор изображения из галереи.
- Несколько похожих экспонатов в результатах.
- Размер/формат и высота показываются в результатах.
- Полный паспорт экспоната и точное место хранения: зал → стеллаж → витрина → полка → слот.
- Админка для загрузки фотографий и заполнения данных позже.
- `fill_db.py` добавляет фотографии в SQLite без удаления существующей коллекции.
- `bot.py` для Telegram.
- Telegram работает через webhook в этом же Render Web Service — отдельный Worker не нужен.
- Опциональная кнопка «🔍 Найти досье» через Gemini + Google Search, если задан `GEMINI_API_KEY`.
- Нет Torch/FAISS/Sentence Transformers на старте, чтобы не ловить OOM на Render.

## Render
Нужен только один Web Service.

Environment Variables:
- `BOT_TOKEN` — новый токен Telegram-бота из BotFather.
- `WEBAPP_URL` — `https://popov-toy-museum.onrender.com`
- `FLASK_SECRET` — любая длинная случайная строка.
- `ADMIN_KEY` — можно задать для будущей защиты админки.
- `GEMINI_API_KEY` — необязательно, для «Найти досье».
- `GEMINI_MODEL` — необязательно.

При старте `app.py` автоматически вызывает Telegram `setWebhook` на:
`WEBAPP_URL/telegram/webhook`.

## Локальный запуск
```bash
pip install -r requirements.txt
python fill_db.py
python app.py
```

Для ручной установки webhook:
```bash
python bot.py
```

## Фотографии
Положите ваши 15 фотографий в папку `photos/` и выполните:
```bash
python fill_db.py
```

Существующие записи не удаляются. Новым фотографиям присваиваются номера `INV-00001`, `INV-00002` и т.д.
Неизвестные характеристики остаются пустыми — приложение ничего не придумывает.
