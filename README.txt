БОТ — отдельная загрузка

1. Загрузи bot.py и bot_requirements.txt в GitHub вместо старого файла бота.
2. На Railway у сервиса БОТА открой Variables.
3. Добавь:
   BOT_TOKEN = ТОКЕН ИЗ BOTFATHER
4. Не записывай токен внутрь bot.py и не загружай .env в GitHub.
5. Если Railway использует requirements.txt, переименуй bot_requirements.txt в requirements.txt
   (или просто используй содержимое из него).

Mini App от этого изменения не зависит.
